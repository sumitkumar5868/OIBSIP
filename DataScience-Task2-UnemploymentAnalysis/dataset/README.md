# Dataset setup

1. Open the dataset publisher page: https://www.kaggle.com/datasets/gokulrajkmv/unemployment-in-india
2. Download `Unemployment_Rate_upto_11_2020.csv`.
3. Save the CSV in this `dataset/` folder with this exact filename:
   `Unemployment_Rate_upto_11_2020.csv`
4. Run `unemployment_analysis.ipynb` from the project folder or repository root.

The notebook checks the dataset structure and dates rather than trusting the filename. Its executed results refer to a 267-row file covering 31 January through 31 October 2020.

The dataset is not included in the project ZIP because redistribution permission has not been confirmed. Follow the publisher's licence/terms.
