# Dataset setup

The project notebook expects a CarDekho-style CSV in this folder named `CarDekho_Dataset.csv` or `car_data.csv`.

Dataset source page: https://github.com/pujarisurakshashankar/car-market-trend-analysis/blob/main/data/CarDekho_Dataset.csv

If automatic download in the notebook fails, download the CSV from the source page and place it here. Review the dataset source's terms before redistributing the CSV. The CSV is intentionally not bundled in this ZIP.
